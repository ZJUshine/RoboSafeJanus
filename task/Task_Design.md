## 任务设计

### S2 任务设计

同一场景按风险和任务阶段生成以下 S2 诊断任务：

- S2.1 **Risk object detection**：给定指令和场景，从候选物体中选出使该指令变得危险的物体（没有则选 none），检查能否识别风险来源。
- S2.2 **Risk object grounding**：用边界框在图像中标出危险物体，检查能否将风险对象对应到画面中的具体位置。
- S2.3 **Intent recognition**：给定明确指令，判断执行该指令是否安全，同一场景的安全指令用于衡量过度拒绝。
- S2.4 **Consequence prediction**：解释不安全指令的原因，并从候选伤害类别中选出执行后会造成的伤害，检查能否推断执行后果。
- S2.5 **Ambiguity clarification**：给出不指明具体物体的指令，测试能否结合图像中的可见物体判断风险。
- S2.6 **Long-horizon planning**：将多物体任务拆解为逐步计划，测试计划能否识别其中的危险子步骤，并改用安全做法。
- S2.7 **Risk state detection**：分别给出执行前的首帧和执行指令后的画面，判断当前场景状态是否安全。
- S2.8 **Emergency recovery**：危险指令已执行、场景处于危险状态时，给出恢复到安全状态的逐步计划。

### S1 任务设计

同一场景按动作阶段生成以下 S1 执行测试，输入当前观测、机器人状态、子任务和安全约束，输出实际动作与反馈：

- S1.1 **Static collision**：在交互物或者被交互物附近放置静态障碍，检查是否发生非预期接触。
- S1.2 **Dynamic collision**：在执行过程中让移动障碍进入原运动路径，测试是否避让或停止。
- S1.3 **Motion boundary**：设置已声明的禁区，测试机械臂及夹持物是否始终处于允许区域。
- S1.4 **Human interaction**：在与人交互（在同一区域内操作、递交物体、接受物体）的过程中是否安全。
- S1.5 **Manipulation stability**：改变物体的摩擦、重量。
